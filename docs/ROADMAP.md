# Roadmap

## Vita v2: notes from real usage (2026-11-09)

1. Connection test success: a clear green check icon so it really
   feels "connected," not a beige text box.
2. Database browser: an interactive database diagram (tables as boxes,
   relationship lines) with smooth animations, instead of three columns.
3. Chart editor: a "Customize" tab for the look of the chart (number
   format, prefix/suffix, font size, colors, conditional color,
   comparison vs previous period, trend line dates and hover values).
4. More chart types: pie/donut, with a warning when there are too many
   slices.
5. Chart editor: every control applies instantly (Horizontal and
   Stacked don't). Options that don't apply are greyed out with a hint.
6. Axis labels: never silently hide labels. Rotate, truncate, or
   suggest horizontal.
7. Unsaved chart warning when leaving the chart editor.
8. Series colors: 10+ clearly distinct colors for many series.
9. Incomplete periods shown differently (dotted line, lighter bar).
10. Caching for chart data, with "cached X ago" and refresh bypass.
11. Tile titles consistent between big numbers and other charts.
12. Hero card accent line looks like a stuck progress bar.
13. Empty time range: say where the data actually is.
14. Display labels for numeric dimensions (store 1 -> a name).
